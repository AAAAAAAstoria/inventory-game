# Inventory Game – 多仓库多门店库存运输决策教学系统

## 项目简介

本项目是一个基于多仓库、多门店、多SKU库存运输场景设计的教学决策游戏系统。

系统通过分阶段机制，引导用户理解库存约束、运输成本、缺货成本以及多约束决策问题的建模逻辑，适用于运筹优化与供应链管理课程教学。

---

## 游戏阶段说明

### 阶段一：基础库存决策

- 考虑仓库库存约束  
- 考虑门店需求约束  
- 计算运输成本与缺货成本  
- 玩家进行人工运输决策输入  

目标函数：

总成本 = 运输成本 + 缺货成本

---

### 阶段二：多约束决策

在阶段一基础上新增：

- 直营门店仓储容量限制  
- 直营门店预算约束  
- 普通商超进货上限  
- 不同运输方式成本差异  

系统自动校验约束并返回违规提示。

---

## 技术栈

- 前端：HTML / CSS / JavaScript  
- 后端：Node.js / Express  
- 数据存储：MySQL / 文件存储  
- 架构模式：前后端分离，全栈结构

## 项目结构

client/     前端界面
server/     后端逻辑
shared/     公共模型与类型定义
drizzle/    数据库结构与配置

---

## 核心建模逻辑

决策变量：

- 仓库 → 门店 → SKU 运输量  

目标函数：

Minimize (运输成本 + 缺货成本)

主要约束包括：

- 仓库库存限制  
- 门店需求约束  
- 门店容量约束  
- 门店预算约束  
- 运输方式约束
